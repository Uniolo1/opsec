# OPSEC
A program, written in C99, for detecting [opsec](https://www.urbandictionary.com/define.php?term=opsec) mistakes. UNLICENSE'd because adding copyright information or suing somebody would be bad opsec. (Technically) works on Windows but is intended for POSIX systems.
